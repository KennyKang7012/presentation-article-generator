## 一句話摘要

AI Agent 正把 AI 從「被動回答」推進到「目標導向、自主規劃、調用工具並完成任務」的新階段；企業的競爭重點將從會不會使用生成式 AI，轉向能否設計安全、可治理、可被 AI Agent 理解與操作的數位工作流。

## 核心重點

1. **AI Agent 與 Chatbot/RPA 的本質差異在自主性**  
   傳統 Chatbot 多為一問一答，RPA 多依固定 SOP 執行；AI Agent 則能理解目標、拆解任務、調用工具、觀察結果並修正路徑。

2. **成熟 Agent 系統由 7 個核心架構組成**  
   感知層、Core LLM、記憶體系、推理與規劃、行動執行、觀測與回饋、學習迴路，共同形成「理解 → 規劃 → 行動 → 觀測 → 調整」的閉環。

3. **企業應用價值在於流程壓縮與智慧工作流**  
   AI Agent 可用於個人數位分身、企業營運代理與多代理協作，例如自動比價、Lead Scoring、客製化開發信、HR 流程、客服退換貨與多 Agent 任務分工。

4. **導入風險集中在幻覺、資安與權限治理**  
   Agent 會實際操作工具，因此錯誤判斷可能造成更大後果；企業需導入 Human-in-the-loop、RBAC、地端部署、Prompt Injection 防禦與稽核日誌。

5. **AI Agent 正改寫搜尋與 SEO 的基礎假設**  
   未來使用者可能不再親自搜尋與點擊網站，而是由 Agent 代為搜尋、篩選、比較、甚至完成交易。品牌能否被 Agent 找到、信任、引用與操作，成為新的競爭關鍵。

6. **從 SEO 走向 AAO / AXO**  
   AAO（AI Agent Optimization）強調讓 Agent 找得到、願意引用、能夠行動並可控地存取內容；AXO（AI eXperience Optimization）則是同時優化人類與 AI 代理的數位體驗。

**視覺**：AI 演進五階段階梯。

### Slide 3：AI Agent、Chatbot、RPA 的差異

**重點**：
- Chatbot：被動回覆，一問一答。
- RPA：照固定 SOP 執行，遇到意外容易停機。
- AI Agent：目標導向、可自主規劃、調用工具並修正策略。

**視覺**：三欄比較矩陣。

### Slide 4：7 大核心架構

**重點**：
- 感知層：讀取文字、圖片、語音或畫面。
- Core LLM：理解自然語言並轉成結構化目標。
- Memory：短期上下文、長期偏好與 RAG 知識檢索。
- Reasoning & Planning：拆解任務與決定順序。
- Action / Tools：呼叫 API、瀏覽器、資料庫或程式。
- Observation & Feedback：觀測結果並回送規劃層。
- Learning Loop：透過回饋與成敗紀錄改善決策。

**視覺**：七模組環形架構圖。

### Slide 5：運作閉環：東京機票與行程案例

**重點**：
- 感知：辨識目的地、時間、預算與任務類型。
- 規劃：拆成航班、飯店、景點、交通與行事曆。
- 行動：呼叫訂票、訂房、地圖與日曆工具。
- 觀測調整：遇到客滿或失敗，自動回到規劃層找替代方案。
- 學習：記住偏好，下次推薦更貼近需求。

**視覺**：五步驟流程圖。

### Slide 6：三類實際應用場景

**重點**：
- B2C：個人數位分身、自動比價、表單與行事曆、收件匣管理、研究助理。
- B2B：Lead Scoring、客製化開發信、HR 流程、客服退換貨。
- 開發者：LangChain/LangGraph、AutoGen、CrewAI、Google A2A。

**視覺**：B2C / B2B / Developer 三區塊。

### Slide 7：企業導入挑戰與治理解法

**重點**：
- 幻覺與決策失控：關鍵節點需 Human-in-the-loop。
- 資安與資料外洩：導入地端部署、最小權限、Prompt Injection 防禦。
- 可追蹤性：使用稽核日誌記錄每次 Agent 操作。

**視覺**：風險到控制措施對照圖。

### Slide 8：搜尋行為典範轉移

**重點**：
- 傳統 SEO 假設：人類搜尋、點擊、進站。
- Agent 時代：使用者把搜尋、篩選、比較與交易外包給 AI Agent。
- 新競爭關鍵：網站能否被 Agent 找到、信任、引用與操作。

**視覺**：舊搜尋漏斗 vs 新 Agent 任務流。

### Slide 9：AAO 四大優化方向

**重點**：
- 找得到：結構化資料、語義化 HTML、乾淨 API。
- 願意引用：E-E-A-T、作者資訊、可驗證數據與引用。
- 能行動：讓網站具備預約、查詢、交易等可操作介面。
- 保護自己：robots.txt、AI 爬蟲協議與版權標註。

**視覺**：四象限 AAO 框架。

### Slide 10：從 SEO 走向 AXO

**重點**：
- SEO 仍是基礎，但未來需同時服務人類與 AI 代理。
- AXO 核心是 AI 代理造訪網站時的體驗最佳化。
- 越早佈局 AXO，越能在 Agent 代搜尋與代交易時代取得先機。

**視覺**：SEO → AAO → AXO 演進路線。

### Slide 11：導入行動指南

**重點**：

- 把資料、權限、工具 API 與審核節點先設計清楚。
- 建立 Agent 可讀、可信、可操作的網站與內容基礎。
- 用稽核與回饋資料持續優化 Agent 工作流。

- 數位行銷下一步，是讓品牌同時被人類與 AI Agent 理解、信任並操作。

## 行動指南

### 入門順序

1. 先分清楚 Chatbot、RPA 與 AI Agent 的差異。
2. 畫出自家流程中可被 Agent 接手的任務閉環。
3. 檢查資料來源、工具 API、權限與人工審核節點。
4. 盤點網站是否具備結構化資料、E-E-A-T 訊號與可操作介面。
5. 從單一高價值流程試點，逐步擴展到多 Agent 協作。

### 推薦練習題

1. 將「客服退換貨」流程拆成 Agent 的感知、規劃、行動、觀測、學習五步驟。
2. 為品牌官網設計一份 AAO 檢核表。
3. 找出一個適合導入 Human-in-the-loop 的高風險節點。
4. 比較 SEO、AAO、AXO 在目標、內容格式、技術基礎與成效指標上的差異。

### 決策檢核問題

1. 這個流程是否足夠高頻、重複且有清楚目標？
2. Agent 需要存取哪些內部系統與資料？權限是否可最小化？
3. 哪些操作需要人工確認？
4. 網站內容是否足以讓 AI Agent 找到、理解、引用與行動？
