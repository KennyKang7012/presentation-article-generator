# AI Agent 入門：簡報大綱摘要與學習指南

來源文章：Doris〈AI Agent 入門：解構核心原理與框架，輕鬆打造自主智慧〉，vocus，2025-02-24 發佈、2025-08-13 更新。  
原文網址：https://vocus.cc/article/67ad5e12fd8978000196bb04

## 一句話摘要

AI Agent 是能感知環境、拆解任務、使用工具並從記憶中學習的自主智慧系統；它的價值不只在自動化重複工作，更在於改變人與 AI 協作、決策與營運治理的方式。

## 核心重點

1. **AI Agent 不只是聊天工具**  
   它不是被動回覆指令，而是能根據目標與環境狀態，自主判斷、規劃並採取行動的智慧夥伴。

2. **四個核心能力構成 Agent 的行為基礎**  
   - 自主決策：降低人工逐步介入。
   - 環境感知：理解文字、圖像、聲音或系統狀態。
   - 智慧規劃：把目標拆解成可執行步驟。
   - 自我進化：透過互動、回饋與記憶持續優化。

3. **典型架構可視為「感知、規劃、行動、記憶」迴路**  
   Agent 先接收環境資訊，再由 LLM 或規劃模組拆解任務，接著使用工具或服務執行行動，最後把結果與經驗保存到記憶中。

4. **框架是開發基石，但不是全部**  
   LangChain 適合快速整合與模組化開發，AutoGen 強調多智能體協作；實際落地仍需定義任務、設計架構、整合工具、訓練評估、部署監控。

5. **導入 Agent 的真正限制在治理與成本**  
   高維運成本、資料安全、法律責任、優質資料不足、算力與環境資源消耗，都是企業導入前必須評估的限制。

6. **短期適用場景偏向大量、重複、規則可拆解的工作**  
   文章提醒不必過度恐慌，因為開發與維運 Agent 的成本仍高；短期比較可能取代的是高重複性、高規模化的任務。

## 簡報敘事線

簡報建議以「從概念到落地」為主軸：

1. 先用市場與工作模式轉變作為開場。
2. 釐清 AI Agent 與一般 AI 工具的差異。
3. 拆解核心能力與系統架構。
4. 用餐廳服務生案例讓抽象流程具體化。
5. 說明開源框架與基礎開發流程。
6. 最後回到企業導入時的成本、治理、資源與永續問題。

### Slide 1：封面

### Slide 2：為什麼現在談 AI Agent

**重點**：
- 生成式 AI 之後，焦點轉向可自主執行任務的 AI Agent。
- 2025-2026 年被視為 Agent 廣泛應用的重要窗口。
- 價值不只是效率提升，而是工作模式重組。

### Slide 3：AI Agent 是什麼

**重點**：
- 能感知環境。
- 能自主決策與規劃。
- 能使用工具採取行動。
- 能依靠記憶與回饋持續改善。

### Slide 4：四大核心能力

**重點**：
- Autonomous：自主決策。
- Perception：環境感知。
- Planning：智慧規劃。
- Self-Improving：自我進化。

### Slide 5：核心架構迴路

**重點**：
- Perception：接收與處理資訊。
- Planning：拆解任務與制定方案。
- Action：呼叫工具、服務或系統完成任務。
- Memory：保存上下文、經驗與長短期資訊。

### Slide 6：AI Agent 參考架構圖

**重點**：
- 依參考截圖重新繪製 AI Agent 架構全景圖。
- 中心為 AI Agent，四周連接 Perception、Planning、Action、Memory。
- 周邊能力包含感測器、處理單元、多模態模型、規劃演算法、LLM、知識圖譜、推理引擎、工具、外部服務、知識庫與長短期記憶。

### Slide 7：感知與規劃拆解

**重點**：
- Perception 負責把環境輸入轉成 Agent 可理解的狀態。
- Planning 負責結合 LLM、知識圖譜、推理引擎與規劃演算法，輸出可執行計劃。
- 這一層的品質會直接影響後續 Action 是否正確。

### Slide 8：行動與記憶閉環

**重點**：
- Action 透過工具、API、外部服務與回饋機制執行任務。
- Memory 分為原始知識庫、短期記憶與長期記憶。
- 企業導入時需搭配權限、審計、人工覆核與成本監控。

### Slide 9：餐廳服務生案例

**重點**：
- 觀察顧客：Perception。
- 推薦套餐與加購策略：Planning。
- 介紹菜單與完成點餐：Action。
- 根據過往銷售經驗加推紅酒：Memory。

### Slide 10：框架選型與開發流程

**重點**：
- LangChain：模組化、多語言、整合快速。
- AutoGen：多智能體協作，適合複雜任務。
- 開發流程：定義任務、選擇框架、設計架構、整合工具、訓練評估、部署監控。

### Slide 11：導入挑戰

**重點**：
- 信任、安全與法律責任。
- 資料外洩風險與優質資料不足。
- 算力、水資源與環境成本。
- 維運成本不一定低於人工。

### Slide 12：學習指南

**重點**：
- 先懂 Agent loop，再看框架。
- 用小任務練習工具調用與記憶設計。
- 學會評估輸出品質、安全與成本。
- 從單 Agent 走向多 Agent 協作。

### Slide 13：結論

**重點**：
- AI Agent 是「能做事的 AI 系統」，不是單純問答模型。
- 成功導入取決於任務拆解、工具整合、治理與持續監控。
- 下一階段競爭力來自人與 Agent 的工作流設計。

## 學習指南

### 入門順序

1. **概念層**：理解 Agent、LLM、工具、記憶、規劃的差異。
2. **架構層**：畫出 Perception、Planning、Action、Memory 的資料流。
3. **實作層**：選一個小任務，例如自動整理文章摘要或查詢資料，建立最小可行 Agent。
4. **評估層**：檢查任務成功率、錯誤恢復、資料安全與執行成本。
5. **治理層**：加入權限控管、審計紀錄、人工覆核與監控告警。
