# Article to Presentation Output Checklist

Use this checklist before final delivery.

## Source

- [ ] Source URL or Markdown path is recorded.
- [ ] Article title is captured.
- [ ] Author/date are captured when available.
- [ ] Irrelevant page content is excluded.

## Markdown

- [ ] One-sentence summary exists.
- [ ] Core takeaways are grouped logically.
- [ ] Slide outline has numbered slide sections.
- [ ] Learning guide, action guide, or decision guide fits the audience.
- [ ] Source citation is included.

## Deck

- [ ] Deck has a clear cover and conclusion.
- [ ] Each slide has a visual element.
- [ ] Dense concepts are split across multiple slides.
- [ ] Source is cited unobtrusively.
- [ ] Diagrams are redrawn or generated rather than blindly pasted when appropriate.

## QA

- [ ] PPTX opens as a valid zip.
- [ ] pptx validator passes when dependencies are available.
- [ ] Slide count and slide titles are checked.
- [ ] Placeholder text check passes.
- [ ] Visual sanity check is performed.
- [ ] Any QA limitation is reported.
